# CCHobby

CCHobby é uma plataforma web de **organização pessoal, hábitos, metas e finanças**, criada para ajudar o usuário a acompanhar sua evolução diária de forma simples, visual e eficiente.

O projeto reúne em um só lugar ferramentas de produtividade e controle financeiro, com um dashboard moderno, responsivo e intuitivo.

(Link: https://cc-hobby.vercel.app/)

---

## ✨ Sobre o projeto

O **CCHobby** foi desenvolvido com a proposta de unir:

- acompanhamento de hábitos
- metas mensais
- calendário dinâmico
- gráficos de produtividade
- controle financeiro
- dashboard visual e organizado

A ideia é permitir que o usuário consiga acompanhar sua rotina e sua vida financeira em uma única plataforma.

---

## 🚀 Funcionalidades

### Hábitos e produtividade
- Dashboard com visão geral do mês
- Acompanhamento de hábitos diários
- Calendário interativo
- Gráfico de produtividade
- Gráfico de hábitos do mês
- Controle de metas mensais
- Sistema de progresso e evolução

### Finanças
- Área separada para controle financeiro
- Cadastro de entradas e saídas
- Visualização de saldo disponível
- Gráfico para acompanhar distribuição de gastos
- Organização financeira de forma prática e visual
